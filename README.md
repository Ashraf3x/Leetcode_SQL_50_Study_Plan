## 📚 About the Study Plan
 
This repository follows the structure of the study plan exactly.  
Each main folder represents a **topic or category** in SQL. Within each folder, you'll find separate folders for each problem. Each problem folder contains:
 
1. **README.md** – Complete explanation of the problem, hints, step-by-step solution, and SQL code.  
2. **solution.sql** – SQL code only.  
3. **problem.yml** – Metadata including difficulty, tags, LeetCode link, and solved status.
> This structure ensures that each problem is **self-contained** and easy to navigate.

## 📝 How Each Problem is Structured
 
Inside each problem folder:
 
### 1️⃣ Problem Requirements
The original LeetCode problem description, sometimes with extra clarifications or examples.
 
### 2️⃣ Hints
Step-by-step hints to guide your thinking if you're stuck. Take each hint for 5-10 minutes before reading further.
 
### 3️⃣ Explanation
Detailed breakdown of the logic and approach used to solve the problem. Read this **after attempting the problem yourself**.
 
### 4️⃣ SQL Solution
The final SQL query, explained and ready to run.
