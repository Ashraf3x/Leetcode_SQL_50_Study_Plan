# 🛠 Scripts

Utility scripts to automate repository maintenance.

## Available Scripts

### 1. update_progress.py
Updates the PROGRESS.md file based on solved problems.

**Usage:**
```bash
python scripts/update_progress.py
```

### 2. generate_index.py
Generates the INDEX.md file with all problems listed.

**Usage:**
```bash
python scripts/generate_index.py
```

## Requirements

```bash
pip install pyyaml
```
